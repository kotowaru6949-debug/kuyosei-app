# ☸️ 満正寺式 九曜星占盤 ＆ 宿星相性・結婚診断アプリ

鳥取・倉吉「満正寺（まんしょうじ）」の巨大九曜星占盤（宿曜二十七宿・三九の秘法・九曜星）をブラウザ上で体験し、友達や気になる人との相性・結婚観・アプローチ攻略法・歴史上の偉人例えを占えるWebアプリケーションです。

## ✨ 主な機能

1. **☸️ 九曜星占盤（2人の相性・三九の秘法）**
   - 自分の宿星に赤字の「**命**」を合わせる自動回転ギミック（手動ドラッグ回転にも対応）
   - 「命・業胎・栄親・友衰・危成・安壊」× 距離（近距離・中距離・遠距離）の相性判定
   - **🏯 歴史上の名コンビ・宿敵例え**、**🌟 徹底ベタ褒め（最強ポイント）**、**💣 辛口ダメ出し（破綻・ケンカの地雷）**
2. **💍 星札（黄札）・結婚相手・アプローチ・九曜星運勢**
   - 満正寺の「黄札」スタイルによる27宿別診断（**歴史上の偉人タイプ・徹底ベタ褒め・劇薬の毒舌戒め**）
   - 結婚観・どういう人が結婚に合っているか・宿曜で結婚相性が最高な宿星バッジ
   - 自分がアプローチする時の秘訣 ＆ その人を振り向かせる攻略法
   - 数え年による九曜星（当年星・本命星）と9年周期バイオリズム
3. **👥 選んだ人とメンバー全員の相性一覧（1対Nフォーカス表示 ＆ 全員総当たり表）**
   - メンバーを1人選ぶだけで、その人と登録メンバー全員の相性・結婚相性・アプローチ法をスコア順に一覧表示
   - 登録メンバーの名前・生年月日変更（`✏️` ボタン）
4. **📤 友達への共有（URL・LINE結果テキスト・単一HTML書き出し・共有コード）**
   - GitHub Pages等で公開すれば **`?members=...` 付きURL** で登録メンバーごと友達に共有可能

## 🚀 GitHub Pages での公開手順

1. GitHubのリポジトリ画面で **Settings** → **Pages** を開く
2. **Build and deployment** の **Source** を `Deploy from a branch` に設定
3. **Branch** を `main` / `/(root)` にして **Save** をクリック
4. 数十秒〜1分ほどで `https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/` が公開されます！
   - 公開後のURLでアプリを開き、「📤 友達に共有・結果を送る」→「④ Web公開用URL」をコピーしてLINEで送れば、友達のスマホからそのまま見られるようになります。
